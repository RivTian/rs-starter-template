# 1. Record architecture decisions

Date: 2026-09-20

## Status

Accepted

## Context

Decisions about structure are easy to forget and expensive to relitigate.

## Decision

Record every architecturally significant decision as a short file in `docs/adr/`, numbered,
with Status / Context / Decision / Consequences. Supersede rather than edit.

## Consequences

New contributors read the reasoning, not just the result. Reviewers can ask "which ADR?".
